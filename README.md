# ✨ Patri Escudero · Make Up Artist — Web Personal

Página web personal y portafolio profesional de **Patricia Escudero Corzo**, maquilladora profesional especializada en cine, series, teatro, beauty y caracterización FX.

> 🌐 Desplegada en **Cloudflare Pages**

---

## 📸 Vista previa

La web cuenta con una estética editorial cálida en tonos terracota, nude y cream, inspirada en el mundo del maquillaje profesional y la alta costura.

---

## 🎨 Secciones

| Sección | Descripción |
|---------|-------------|
| **Hero** | Presentación con nombre, especialidad, estadísticas y CTA |
| **Sobre mí** | Biografía, formación académica y especialidades |
| **Servicios** | 6 tarjetas: Beauty & Novias, Cine/Series/TV, Caracterización & FX, Teatro, Publicidad/Editorial, Formación |
| **Proyectos** | Filmografía real con tabs de filtrado por categoría (Series, Cortos, Teatro, Publicidad) |
| **Contacto** | Datos de contacto + modal con formulario interactivo |
| **Footer** | Redes sociales y copyright |

---

## 🛠️ Tecnologías

- **HTML5** — Estructura semántica y accesible
- **CSS3** — Vanilla CSS con variables custom (design tokens), animaciones y responsive design
- **JavaScript** — Vanilla JS para interactividad (modal, tabs, scroll reveal, counters)
- **Google Fonts** — Cormorant Garamond (serif) + Plus Jakarta Sans (sans-serif)
- **Font Awesome 6** — Iconografía profesional
- **Cloudflare Pages** — Hosting y despliegue
